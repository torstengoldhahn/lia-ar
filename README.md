# Lia – AR-Avatar zur generalistischen Pflegeausbildung

AWO Bamberg Stadt und Land e. V.

Lia ist eine sprechende 3D-Pflegefachperson, die per Augmented Reality auf einer gedruckten Karte (oder direkt auf dem Tisch) steht und die generalistische Pflegeausbildung erklärt.

- `index.html` – AR-Seite (Karten-Tracking mit MindAR, WebXR-Tischmodus, Vorschau, Druckkarte mit QR-Code)
- `lia-ziel.mind` / `lia-ziel.jpg` – Kartenmotiv und Tracking-Daten
- `ANLEITUNG.md` – Einrichtung und Nutzung
